# Edgelite Startup Financial Model

A three-year startup operating model built in Excel.

## Features

- Downside / Base / Upside scenario analysis
- Customer acquisition funnel
- Revenue forecasting
- Cost forecasting
- Monthly P&L
- Cash Flow Statement
- Balance Sheet
- Burn rate and runway analysis
- Cap table and investor return analysis
- Executive dashboard

## Model Structure

1. Assumptions
2. Customer Acquisition & Revenue
3. Cost Build
4. Monthly P&L
5. Cash Flow Statement & Balance Sheet
6. Runway & Break-even Analysis
7. Cap Table & Investor Returns
8. Dashboard

## Key Finance Concepts Demonstrated

- Revenue driver forecasting
- Scenario analysis
- Three-statement modeling
- Startup unit economics
- Venture capital valuation
- Runway and burn-rate analysis
